**FARM-16 Pre-Spec v0.1 — Contextualization Coverage Score (CCS)**

*Problem:* Verisleight (true-in-isolation, misleading-in-context) has no automated detection layer. FARM-15 (falsification reward scaling) provides economic retrospective pressure but not prospective prevention.

*Mechanism:*

```protobuf
// New field on MsgSubmitFact
message ContextDeclaration {
  string temporal_scope   = 1;  // ISO-8601 range, empty = "timeless"
  string geographic_scope = 2;  // ISO-3166-1 alpha-2 or "universal"
  string population_scope = 3;  // free text describing subject population
  repeated string condition_fact_ids = 4;  // prerequisite fact IDs
}
```

*Validator behavior:*
- CCS vote submitted alongside confidence vote (second dimension of the verification round)
- CCS scale: 0–1000 (analogous to confidence 0–1,000,000, but coarser — verisleight is harder to quantify)
- CCS aggregation: stake-weighted mean, same safeMulDiv path as confidence

*Consequences of low CCS (< `MinCCSThreshold`, governance param, default 400):*
- `partial_context = true` flag on the fact record
- Facts inheriting this fact via citation must declare the inherited scope limitation in their own ContextDeclaration
- 20% of knowledge-pool rewards routed to validators who subsequently submit facts that fill the context gap (citation-linked, closes the partial_context flag when CCS of the gap-filling fact is >= `CCSGapCloseThreshold`, default 700)

*Governance params to add:*
```
MinCCSThreshold        uint32  // default 400 — below this, partial_context = true
CCSGapCloseThreshold   uint32  // default 700 — filling-fact CCS needed to close the flag
CCSKnowledgePoolShare  uint32  // BPS, default 200_000 (20%) routed to gap-closers
CCSVoteWeight          uint32  // BPS weight of CCS vote relative to confidence in final reward, default 100_000 (10%)
```

*Interaction with existing FARMs:*
- FARM-15 (falsification reward): complementary — FARM-15 rewards challenging false facts, FARM-16 rewards completing incomplete ones. Different economic levers, same verisleight target.
- AH-4 (method diversity): no conflict — CCS is a separate vote dimension, not part of confidence aggregation.
- FARM-3 (self-citation discount): CCS gap-closers who cite themselves should not receive gap-close rewards — add check: `citer != gapFiller` for the 20% routing.

*Implementation scope (for Gamma):*
