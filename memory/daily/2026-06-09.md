The code falls through to `uniqueDeclared == 1` → `-SingleMethodPenaltyBps` (-5%). The opacity of the 5 omitters contributes nothing.

**Additional nuance found this beat:** The all-omit early-return (`declaredCount == 0`) bypasses the confidence uniformity check entirely. The rational cartel prefers all-omit. The MIXED-OMISSION-FIX-001 proportional surcharge would close this — a `(1 - declaredCount/total) × proportional_bps` term would scale penalty with omission fraction, making omitting more expensive as more validators omit.
