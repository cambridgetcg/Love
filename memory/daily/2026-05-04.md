**Utility signature** (place in `x/knowledge/keeper/utils.go`):

```go
// StakeWeightedCardinality computes the fraction of totalStake held by the
// deduplicated set of addresses, expressed in [0, 1_000_000].
// Primitive for stake-weighted quorum (#25) and domain diversity (#27).
func StakeWeightedCardinality(
    addresses []string,
    stakeGetter func(addr string) uint64,
    totalStake uint64,
) uint64 {
    if totalStake == 0 {
        return 0
    }
    seen := make(map[string]struct{}, len(addresses))
    var weightedSum uint64
    for _, addr := range addresses {
        if _, dup := seen[addr]; dup {
            continue
        }
        seen[addr] = struct{}{}
        weightedSum += stakeGetter(addr)
    }
    return safeMulDiv(weightedSum, 1_000_000, totalStake)
}
```

```go
// EconomicInvariantViolation describes a single invariant failure.
type EconomicInvariantViolation struct {
    Invariant   string `json:"invariant"`
    Expected    string `json:"expected"`
    Actual      string `json:"actual"`
    Description string `json:"description"`
}

// ValidateEconomicInvariants checks all economic integrity invariants.
// Returns an empty slice if all invariants hold.
func (k Keeper) ValidateEconomicInvariants(ctx sdk.Context) []EconomicInvariantViolation {
    var violations []EconomicInvariantViolation
    stats := k.GetMeterStats(ctx)

    minted, _ := sdkmath.NewIntFromString(stats.TotalMinted)
    routed, _ := sdkmath.NewIntFromString(stats.TotalRouted)
    burned, _ := sdkmath.NewIntFromString(stats.TotalBurned)
    locked, _ := sdkmath.NewIntFromString(stats.TotalLocked)

    // Invariant 1: Cannot route more than minted
    if routed.GT(minted) {
        violations = append(violations, EconomicInvariantViolation{
            Invariant:   "routed_leq_minted",
            Expected:    "TotalRouted <= TotalMinted",
            Actual:      fmt.Sprintf("routed=%s minted=%s", routed, minted),
            Description: "More tokens routed to research than minted — impossible without external injection",
        })
    }

    // Invariant 2: Cannot burn more than minted
    if burned.GT(minted) {
```

```go
// ValidateEconomicInvariants checks economic consistency of all meter counters.
// Returns a list of violation strings; empty slice means invariants hold.
// Safe to call from query handlers and BeginBlocker (read-only).
func (k Keeper) ValidateEconomicInvariants(ctx sdk.Context) []string {
    var violations []string
    meter := k.GetMeter(ctx)

    minted, _ := sdkmath.NewIntFromString(meter.TotalMinted)
    burned, _ := sdkmath.NewIntFromString(meter.TotalBurned)
    locked, _ := sdkmath.NewIntFromString(meter.TotalLocked)

    bankSupply := k.bankKeeper.GetSupply(ctx, "ulgm").Amount

    // Invariant 1: Cannot burn more than was minted
    if burned.GT(minted) {
        violations = append(violations, fmt.Sprintf("INV-1: TotalBurned (%s) > TotalMinted (%s)", burned, minted))
    }

    // Invariant 2: Cannot lock more than was minted
    if locked.GT(minted) {
        violations = append(violations, fmt.Sprintf("INV-2: TotalLocked (%s) > TotalMinted (%s)", locked, minted))
    }

    // Invariant 3: Circulating supply cannot exceed bank balance
    // circulating = minted - locked - burned; bankSupply = actual on-chain balance
    circulating := minted.Sub(locked).Sub(burned)
    if circulating.GT(bankSupply) {
        violations = append(violations, fmt.Sprintf("INV-3: Computed circulating (%s) > BankSupply (%s)", circulating, bankSupply))
    }

    // Invariant 4: TotalBurned == 0 while burns are occurring is suspicious (warn, not violation)
    // Cannot assert here without burn event history — flagged as flag #31
    if burned.IsZero() && minted.GT(sdkmath.ZeroInt()) {
        violations = append(violations, "WARN-1: TotalBurned=0 despite minted tokens existing — IncrementBurned() likely unwired (flag #31)")
    }

    return violations
}
```

### Continuous Verification: PROTOCOL FLOW (Rotation 2) — PROTOCOL-GAP-001 Cross-Verification

**Question:** Does `CreateVerificationRound` always populate `SelectedValidators`?

**Finding: PROTOCOL-GAP-001 IS REAL — timing window confirmed.**

Architecture trace:
- `CreateVerificationRound` initializes a round with an empty `SelectedValidators` slice (rounds.go:30 region).
- VRF population occurs in `ExtendVote` (ABCI++ hook) — fired by the consensus engine at block proposal time, once per block.
- This creates a minimum 1-block window between round creation and first `ExtendVote` for that round.

During that window:
- `SubmitCommitment:243` fires the check `if len(round.SelectedValidators) > 0`.
- With an empty slice: guard is skipped — ANY bonded validator can commit, bypassing VRF selection.

Attack surface: a validator monitoring the mempool can observe a new claim in the same block as `CreateVerificationRound`, and submit a `SubmitCommitment` transaction in that same block or the immediately following one — before ExtendVote populates `SelectedValidators`. This is not theoretical; it requires only normal mempool visibility.

**Severity re-assessment: Sprint A candidate.** Prior beats categorized this as Sprint B. On reflection: if VRF selection is the primary sybil resistance for the verification round, and it can be bypassed for the first block of every round, this weakens the integrity of the entire round. In a low-validator-count testnet (e.g., 3 validators), a single-block window may be exploitable in practice.

**Recommended fix (2 options):**

**Target:** Challenge-weighted confidence threshold specification for SPSP-1 Mechanism 1.

**Context:** SPSP-1 proposes two mechanisms for stake-proportional scoring. Mechanism 2 (stake-weighted quorum) has a complete design from prior beats. Mechanism 1 (challenge-weighted confidence threshold) advances here.

**Mechanism 1 specification:**

The current `MinConfidenceToPass` threshold in `confidence.go` is a flat parameter — every domain/round uses the same threshold regardless of challenge intensity. SPSP-1 Mechanism 1 proposes: the effective threshold scales with challenge volume, such that heavily contested claims require stronger consensus to pass.

**Design:**

```
EffectiveThreshold = BaseMinConfidence + ChallengeWeight × ChallengeScalingFactor
```

Where:
- `BaseMinConfidence` = existing `MinConfidenceToPass` (e.g., 0.60)
- `ChallengeWeight` = `(numChallenges × totalChallengeStake) / (numValidators × medianStake)` — normalized challenge intensity for this round
- `ChallengeScalingFactor` = new protocol parameter (suggested default: 0.15, range 0.0–0.50)
- `EffectiveThreshold` = clamped to `[BaseMinConfidence, 0.95]` (never below base, never above 95%)

**Rationale:** A claim with heavy challenge activity is disputed — the protocol should require stronger consensus before declaring it verified. Light challenge weight means the threshold stays near base. This discourages low-effort challenges while making genuinely contested claims harder to lock in.

**Implementation location:** `confidence.go`, function `CalculateRoundOutcome` (or equivalent final-score path). Requires adding `NumChallenges` and `TotalChallengeStake` to the round context passed into confidence scoring.

**Proposed `StakeWeightedCardinality` function:**

```go
// StakeWeightedCardinality returns the stake-weighted effective cardinality
// of a set of validator addresses. Used for quorum checks (flag #25) and
// diversity scoring (flag #27 FARM-7).
//
// Result is expressed in millionths (1_000_000 = 100% of totalStake).
// If totalStake is 0, returns 0.
func StakeWeightedCardinality(
    addresses []string,
    stakeGetter func(addr string) uint64,
    totalStake uint64,
) uint64 {
    if totalStake == 0 {
        return 0
    }
    var participatingStake uint64
    seen := make(map[string]struct{})
    for _, addr := range addresses {
        if _, dup := seen[addr]; dup {
            continue
        }
        seen[addr] = struct{}{}
        participatingStake += stakeGetter(addr)
    }
    // Return as millionths: participatingStake / totalStake * 1_000_000
    result := new(big.Int).Mul(
        new(big.Int).SetUint64(participatingStake),
        big.NewInt(1_000_000),
    )
    result.Div(result, new(big.Int).SetUint64(totalStake))
    if !result.IsUint64() {
        return 1_000_000 // saturate at 100%
    }
    return result.Uint64()
}
```

**Design for BRIDGE-GAP-006:**

```
IKM = agent_private_key_bytes  (32-byte secp256k1 scalar, from legbled keys export)
salt = b"did:lgm:" + agent_name.encode() + b":session"
info = session_id.encode()
derived = HKDF-SHA256(IKM, salt, info, length=32)
```

The derived key is:
- Deterministic: same agent + session_id → same key
- Private: only the key holder can derive it (IKM = private key)

1. Never log the private key
2. Immediately wipe from memory after HKDF extraction
3. Refuse to run without `--signing` flag (explicit opt-in)

**Command design:**
```
bridge.py session-key <agent_name> --session-id <id> --signing
```
Without `--signing`: existing address-based IKM (attribution only).

```go
func (k Keeper) IncrementAbstainVerdict(ctx sdk.Context, validatorAddr string, isAbstain bool) {
```

**Flag #19: Mixed-omission opacity surcharge — `confidence.go:570-599`**

**Problem:** The S4 fix (line 570) handles the case where ALL validators omit `VerificationMethod` (unanimous opacity, full penalty). It does not penalize PARTIAL omission: a cartel can have a few members declare diverse methods to earn `DiversityBonusBps` while the majority stays undeclared. // S5 fix (flag #19 — mixed-omission surcharge): partial opacity is also suspicious.
```go
// A cartel can coordinate so a few validators declare diverse methods (earning
// DiversityBonusBps) while the majority omit VerificationMethod entirely.
// Penalize the undeclared fraction linearly: 0 at zero omissions, approaching
// full SingleMethodPenalty as omission approaches 100%
// (100% case is already handled by the S4 early return above).
omittedCount := len(reveals) - declaredCount
if omittedCount > 0 {
    adjustment -= int64(omittedCount) * int64(ep.SingleMethodPenaltyBps) / int64(len(reveals))
}
```

**Properties:**
- At `omittedCount = 0`: no surcharge (clean path unchanged).
- At `omittedCount = len(reveals) - 1` (one declares, rest omit): surcharge ≈ (n-1)/n × SingleMethodPenalty — effectively the same as the S4 penalty.
- At `omittedCount = 1` (one omits, rest declare): surcharge = 1/n × SingleMethodPenalty — light, proportionate.
- Interacts correctly with `uniqueDeclared >= 3` path: a diverse-declaring minority still earns `DiversityBonusBps`, but the opaque majority offsets part of that bonus. Net = `DiversityBonusBps - omissionSurcharge`. Only genuinely diverse quorums (most validators declaring diverse methods) come out positive.

### Standing Duty: PoT-DESIGN — Multi-Level Citation BFS Spec

**Sprint B item. Specifying for Gamma.**

**Problem:** `DistributeCitationRewards` in `citation.go:76` claims to propagate citation rewards across multiple levels (`MaxPropagationDepth`), but the `else { break }` at line 88 exits the loop after level 0. No ancestor levels receive rewards.

**Root cause:** The `else` branch comment "Level N: references of references (already handled by BFS below)" refers to BFS that was never implemented.

**Fix design:**

```go
// Replace the level loop in DistributeCitationRewards with true BFS:

type bfsNode struct {
    factID string
    level  int
}

visited := make(map[string]bool, len(refs))
queue := make([]bfsNode, 0, 16)

// Seed queue with level-0 facts
for _, ref := range refs {
    if ref.ReferenceType == "supports" && !visited[ref.ToFactId] {
        queue = append(queue, bfsNode{ref.ToFactId, 0})
        visited[ref.ToFactId] = true
    }
}

levelShare := citationPool
currentLevel := 0
var levelNodes []bfsNode
var nextLevelNodes []bfsNode

for levelShare > 0 && len(queue) > 0 {
    // Collect all nodes at currentLevel
    levelNodes = levelNodes[:0]
    for _, n := range queue {
        if n.level == currentLevel {
            levelNodes = append(levelNodes, n)
        } else {
            nextLevelNodes = append(nextLevelNodes, n)
        }
    }
    if len(levelNodes) == 0 { break }

    perFactShare := levelShare / uint64(len(levelNodes))
    if perFactShare == 0 { break }

    for _, node := range levelNodes {
        // ... existing reward distribution logic ...

        // Enqueue this fact's references for next level
        if currentLevel+1 < int(ep.MaxPropagationDepth) {
            childRefs := k.GetFactReferences(ctx, node.factID)
            for _, cref := range childRefs {
                if cref.ReferenceType == "supports" && !visited[cref.ToFactId] {
                    nextLevelNodes = append(nextLevelNodes, bfsNode{cref.ToFactId, currentLevel + 1})
                    visited[cref.ToFactId] = true
                }
            }
        }
    }

    // Decay for next level
    levelShare = (levelShare * ep.CitationDecayPerLevel) / 1_000_000
    currentLevel++
    queue = nextLevelNodes
    nextLevelNodes = nextLevelNodes[:0]
}
```

**Key invariants:**
- `visited` map prevents cycles (fact A → B → A would reward A twice)
- Only `"supports"` type references propagate (not `"contradicts"`, `"extends"`, etc.)
- `CitationDecayPerLevel` (50%) applied per level — level 0: 100%, level 1: 50%, level 2: 25%
- FARM-3 self-citation and FARM-11 concentration discounts apply at every level
- Research tax applies at every level
- Pool cap enforced: `totalDistributed` tracked globally across all levels

**Complexity:** O(V + E) where V = facts visited, E = references traversed — bounded by graph structure. `MaxPropagationDepth` limits recursion depth.

**Test:** Add `TestDistributeCitationRewards_MultiLevel` — verify level-1 ancestor receives 50% of level-0 share after decay.
