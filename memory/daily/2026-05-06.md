### Standing Duty: PoT-DESIGN (Rotation 1)

**Topic: Stratum ceiling vs evidence override — PoT design position**

The current algorithm implements an implicit hierarchy:

```
Base confidence (stake-weighted agreement)
  → Stratum ceiling clamps (domain epistemic reliability)
    → Category ceiling clamps (claim epistemic type)
      → Evidence bonus adds back (claim-level proof quality)
        → Hard cap at 1,000,000 (100%)
```

The evidence bonus can restore confidence past both the stratum and category ceilings. This is either a feature (evidence quality can compensate for domain uncertainty) or a gap (stratum represents physical/structural limits that evidence cannot transcend).

**Design position proposed (PoT-DESIGN-001 amendment):**

Distinguish two ceiling types:
- **Soft ceilings** (category-based): evidence CAN override. A "speculative" claim with exceptional evidence can earn higher confidence.
- **Hard ceilings** (stratum-based): evidence CANNOT override. If a domain's knowledge is structurally limited (e.g., future predictions, unobservable phenomena), no amount of evidence changes the epistemic floor. The stratum ceiling should be absolute.

**Proposed code change (post-Sprint A, low priority):**
Apply evidence bonus BEFORE stratum ceiling, not after. Category ceiling remains soft. Stratum ceiling is the final absolute clamp.

This closes Flag #32 with a principled design decision rather than a hack.
