## 6. Standing Duty: PoT-DESIGN (slot 1, cycle 29)

**Focus: Abstain-as-suppression attack vector and FARM-5 priority escalation**

The VERISLEIGHT SCAN above identified that coordinated abstention is a zero-cost censorship mechanism. This session designs the attack model and defense specification.

**Attack model: Coordinated Abstain Suppression (CAS)**

Conditions:
- Attacker controls validators with stake weight W_attacker.
- Honest participants split between accept/reject, so neither honest bloc reaches W_attacker alone.
- Attacker submits "abstain" for target facts.
- Result: `abstainWeight > acceptWeight && abstainWeight > rejectWeight` → verdict = "abstain".
- The fact does not advance to verified or rejected. It may expire or remain in limbo.
- Cost to attacker: opportunity cost only (no reward for abstaining; no slash for wrong verdict per confidence.go:311).

**Minimum viable suppression stake:**
If accept and reject split 50/50 among honest validators, an attacker needs only `W_honest/2 + 1` stake weight to dominate the abstain bucket. At 33% honest stake split (accept/reject/abstain), an attacker needs only 34% of total stake weight to achieve abstain plurality. This is well below typical Byzantine fault tolerance thresholds (33%).

**Existing mitigations:**
- `PassiveStakingPenaltyBPS = 500_000` (50% reward reduction for non-participants). BUT this applies to validators who do NOT vote at all — abstaining IS participating, so passive penalty does NOT apply to abstainers.
- No current mechanism penalizes deliberate abstention.

**FARM-5 defense specification (design advance):**

FARM-5 should implement an `AbstainVotingTaxBPS` parameter:
- Default: `10_000` (1% of verifier stake, distinct from the 6% wrong-verdict slash).
- Applied in `confidence.go` after verdict determination: if a verifier voted "abstain" AND the final verdict is NOT "abstain", deduct 1% of their committed stake.
- If the final verdict IS "abstain" (legitimate uncertainty is consensus), no tax applied — consensus abstention is valid.
- Effect: deliberate suppression abstainers pay 1% per suppressed fact. Coordinated suppression of N facts costs N × 1% × attacker_stake, creating linear cost pressure against sustained CAS attacks.

**Why 1% (not 50% passive penalty)?**
Abstain is a valid epistemic state (genuine uncertainty). 50% would destroy legitimate abstain votes. 1% is a deterrent that respects valid abstention while pricing out coordinated suppression. The 6% wrong-verdict slash is a reference — abstain-tax should be lower (no epistemic wrong, only strategic cost).

**Implementation path (low risk, isolated):**
1. Add `AbstainVotingTaxBPS uint64` to `ExtendedKnowledgeParams` in `types.go` (default 10_000).
2. In `confidence.go` reward distribution loop, after computing `verdict`: if `reveal.Verdict == "abstain"` AND `result.Verdict != "abstain"`, apply `AbstainVotingTaxBPS` deduction to verifier's reward (similar to existing wrong-verdict slash logic at line 311).
3. Call site: `confidence.go` reward finalization section.
