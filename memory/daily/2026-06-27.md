**Finding 2 — DID INDEX COLLISION: PRECISE MECHANISM OF R2 P2 CONFIRMED.**

R2 (Cycle 270, VALIDATOR SET / STAKING) filed P2: "DID uniqueness bypass — empty-string DID skips guard in RegisterValidator:33." This R3 cycle traces the full consequence of that bypass into the identity bridge.

`RegisterValidator` (x/staking/keeper/msg_server.go:27-37):
```go
did := ""
if msg.Description != nil {
    did = msg.Description.GetIdentity()
}
if did != "" {
    if _, found := k.GetValidatorByDID(ctx, did); found {
        return nil, types.ErrDuplicateDID
    }
}
```

When `did == ""`, the uniqueness guard is skipped entirely. The validator is created with `Did: ""`. Then `SetValidator` (x/staking/keeper/keeper.go:94-96) runs unconditionally:
```go
didKey := types.ValidatorByDIDKey(validator.Did)
return store.Set(didKey, []byte(validator.OperatorAddress))
```

**Collision mechanism:** When `validator.Did == ""`, this writes `ValidatorByDIDKey("") → operatorAddress` with no guard. A second empty-DID validator overwrites this index slot silently. After N empty-DID registrations, `GetValidatorByDID(ctx, "")` returns only the last one — the prior N-1 are permanently orphaned from the DID index while remaining in the validator set (accessible via `GetValidator(ctx, operatorAddress)`).

**Consequence for identity bridge:** Validators orphaned from the DID index cannot be resolved by DID for bridge attestation lookups, HIVE routing, or any identity-bridge operation that goes through `GetValidatorByDID`. The index is corrupted without error — no event, no log, silent overwrite. This refines the R2 P2 finding: not just "uniqueness bypass permits duplicates" but "bypass + unconditional index write = silent index state corruption."

**Severity:** P2 (pre-testnet gate — same severity as R2 finding). No change to gate count. Fix: add `if validator.Did != ""` guard in `SetValidator` before writing the DID index, OR require non-empty DID at `MsgRegisterValidator.ValidateBasic`. Option B is preferred — enforces identity bridge integrity at message validation before state write.
