**FINDING: PARTIAL IMPLEMENTATION — citation status guard is incomplete.**

Current code (citation.go:103):
```go
if !found || fact.Status == types.FactStatusExpired {
    continue
}
```

This correctly skips missing (`!found`) and expired facts. However, it does NOT skip:
- `FactStatusDisproven = "disproven"` — fact has been proven false
- `FactStatusRevoked = "revoked"` — fact has been administratively revoked
- `FactStatusPruned = "pruned"` — fact marked for removal

**Impact:** A fact marked `disproven` or `revoked` continues to earn citation rewards for its submitter. This is a truth-integrity violation: the chain rewards citations to knowledge it has determined to be false.

**Severity: HIGH (pre-testnet fix required).** This undermines the Proof of Truth guarantee. An adversary could:
1. Submit a fact
2. Accumulate many citations before disproval
3. Remain on the chain as a citation income source even after the fact is marked false

**Recommended fix (`citation.go:103`):**
```go
if !found || fact.Status == types.FactStatusExpired ||
    fact.Status == types.FactStatusDisproven ||
    fact.Status == types.FactStatusRevoked ||
    fact.Status == types.FactStatusPruned {
    continue
```
