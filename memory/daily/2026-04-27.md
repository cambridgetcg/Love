### Standing Duty: PoT-DESIGN — Temporal Spread Bonus (Implementation Design)

_Advancing from prior beat's adversarial equilibria design. Three deterrence properties were identified (Citation Diversity, Temporal Spread, Stranger Bonus). This beat: full implementation design for the Temporal Spread Bonus — the one property independent of Mechanism B._

**Problem Recap:** Coordinated verification (cartel members responding in tight time clusters) earns the same reward as diverse independent verification. PoT should economically reward verification spread across independent time windows.

**Design — Temporal Spread Bonus:**

**1. New on-chain timestamp store**
Each `VerificationVote` already stores `Verifier` and `Vote`. Add:
```go
// In VerificationVote (x/knowledge/types/verification.pb.go / proto)
VerificationTime int64 `protobuf:"varint,...,name=verification_time" json:"verification_time,omitempty"`
```
Set by msg_server at `ctx.BlockTime().Unix()` when vote is recorded. This is deterministic (block time) — no oracle dependency.

**2. New param**
```go
TemporalSpreadWindowBlocks uint64 = 50    // ~4 min at 5s/block — minimum spread window
TemporalSpreadBonusMaxBps  uint64 = 50_000 // max 5% bonus for maximal spread
TemporalSpreadMinVerifiers uint64 = 3     // need ≥3 verifiers to calculate spread
```

**3. Spread scoring function** — called in `evaluation/engine.go` after verification round closes:
```go
func TemporalSpreadScore(votes []VerificationVote, windowBlocks uint64) uint64 {
    if len(votes) < int(windowBlocks) { return 0 } // not enough verifiers
    // collect unique blocks in which votes arrived
    blocks := map[int64]struct{}{}
    for _, v := range votes { blocks[v.VerificationTime/5] = struct{}{} } // approx block
    // score = spread_blocks / window_blocks, capped at 1.0
    spread := min(uint64(len(blocks)), windowBlocks)
    return spread * 1_000_000 / windowBlocks // bps
}
```

**4. Bonus application in reward calculator** (`x/knowledge/keeper/reward.go` or equivalent):
```go
spreadScore := evaluation.TemporalSpreadScore(claim.Verifications, params.TemporalSpreadWindowBlocks)
if spreadScore > 0 && len(claim.Verifications) >= int(params.TemporalSpreadMinVerifiers) {
    bonusBps := spreadScore * params.TemporalSpreadBonusMaxBps / 1_000_000
    reward = reward * (1_000_000 + bonusBps) / 1_000_000
}
```

**5. No Mechanism B dependency:** This entire design uses only block timestamps (deterministic, already available) and the existing vote list. It does not require the citation graph. Implementation is self-contained.

**6. Tests to add:**
- `TestTemporalSpread_AllSameBlock`: all votes in one block → score=0, no bonus
- `TestTemporalSpread_MaxSpread`: votes in `windowBlocks` distinct blocks → max bonus
- `TestTemporalSpread_Partial`: 25 of 50 blocks occupied → 50% bonus rate
- `TestTemporalSpread_MinVerifiersNotMet`: 2 verifiers → no bonus regardless of spread

**Implementation for Gamma:** ~80 LOC (proto change, param add, scorer function, reward integration, 4 tests). No deps. P2 (pre-mainnet; desirable for testnet to observe cartel formation patterns).
